# Expert 4 reproduction implementation plan

**Goal:** Train and evaluate Expert 4 independently with BEATs, LAION-CLAP RoBERTa, and SeqCoAttn on the average-score XACLE splits.

**Sources and observed behavior:** MOESCORE sections 2.1–2.3 and TASALIGN sections 3.1 and 3.3 specify layer aggregation, two cross-attentions, max pooling, and a hybrid loss; TASALIGN describes tuning the top two encoder layers. `model/wrapper.py` freezes only the first ten BEATs transformer layers, leaving other backbone parameters trainable. `Basic_comp.py` leaves residual/norm/fusion dropout inactive and its active text path returns 768 dimensions to a 512-dimensional attention layer. `loss/loss_function.py` adds the nonnegative pairwise loss (mean divided by two); its formula differs from the printed paper equation. The confirmed Decision 7 and public implementation both use a plus sign, whereas section 8 of the task shows a minus sign; Decision 7 governs this reproduction. `Train_MOE.py` trains the gate only. Public YAML disables output Tanh; the user explicitly enables it.

**Verified resources:** `MOESCORE.pdf`, `Sun_NPU_Sun_NPU.pdf`, `unilm/beats`, `weights/BEATs_iter3_plus_AS2M.pt`, and `weights/laion-clap.pt` exist. The provided dataset has `train_average.csv` and `validation_average.csv` with headers `wav_file_name,text,average_score,model_ID,model_name`; the alternative names in the task description are handled only when present. A separate local Conda environment has PyTorch and SciPy but lacks TorchAudio and LAION-CLAP. BEATs and CLAP checkpoint structures were inspected; full model compatibility requires the Colab smoke checks. XACLE rules were not found in this checkout; organizer eligibility for both external pretrained models must be confirmed.

**Architecture and policy:** Copy only the Expert 4 functionality into `expert4_repro/`. Load BEATs from its checkpoint configuration with strict state loading and 12-layer checks; collect the initial encoder state plus twelve layer outputs and exclude the former. Train its last two layers and all non-layer backbone parameters, aggregation weights, and audio projection. Load CLAP's RoBERTa branch and pretrained token-wise text projection; freeze unused CLAP modules and the first ten RoBERTa layers. Use two eight-head attentions, their key masks, the released max pooling, and a 1024→2048→1 Tanh head. Query-side padding may influence max pooling; retain released behavior and document it.

**Files:** `expert4_repro/{config,dataset,losses,audio_encoder,text_encoder,seq_coattn,model,trainer,inference}.py`, standalone scripts, `configs/expert4_colab.yaml`, `colab/Finetune_MOESCORE_Expert4.ipynb`, focused synthetic tests, and the requested reproduction report. Checkpoint and metric helpers live in `trainer.py`; validation/test export lives in `inference.py` to keep the standalone path small. Do not alter original expert or gate code.

**Data and training:** Resolve actual CSV headers and optional metadata; validate paths and scores; mono conversion, resampling to 16 kHz, pad/trim to 10 seconds, retain valid lengths, and normalize `(score-5)/5`. Batch 8, Adam at 1e-5 with betas 0.9/0.999, linear warmup and decay, tau 0.25, margin 0.1, plus-weighted 1.0/0.5 loss, seed 42. Default 10% warmup and 50 epochs are assumptions/config defaults, not a confirmed Expert 4 schedule. Evaluate on raw 0–10 scale; save best by validation SRCC and resumable last checkpoint including optimizer, scheduler, scaler, RNG and configuration.

**Colab:** Inspect runtime before installing dependencies, mount Drive, resolve configurable paths with ambiguity errors, use an existing UniLM checkout or sparse clone, record source revision, run real checkpoint/gradient preflight, then train or resume and export validation predictions. Never download data or weights.

**Tests:** Synthetic tests cover shape/mask/loss/data/optimizer/scheduler/checkpoint behavior. Real-checkpoint tests run only when required dependencies and trusted resources are available; record all unavailable tests explicitly. Validate notebook JSON and Python syntax even when ML dependencies are absent.

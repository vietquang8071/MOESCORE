# MGA Expert 2 Fine-tuning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train and evaluate a cosine MGA-CLAP Expert 2 on the available XACLE average-score splits, exporting a checkpoint compatible with MoE Expert2.

**Architecture:** Use the provided upstream ASE for encoding and MSC, with a small local wrapper for cosine scoring and freeze policy. A standalone dataset/CLI handles XACLE 2027's verified schema, 32 kHz waveform conversion, paper hybrid loss, validation metrics, and checkpoint export. Keep the existing MoE untouched until its other expert dependencies are available.

**Tech Stack:** Python 3.10 or newer, PyTorch, SciPy, PyYAML, MGA-CLAP source.

**Spec:** `mga-clap_finetune.md`, with the user's later decision to use cosine directly.

## Global Constraints

- Train with average-score CSV, 7,500 train and 3,000 validation pairs; do not use listener-level rows.
- MGA input is 10 seconds, mono, 32 kHz; score target is `(score-5)/5`.
- Cosine between L2-normalized MSC outputs; no MLP and no pretraining InfoNCE.
- Paper settings: Adam, batch 8, LR 1e-5, warm-up/linear decay, clipped MSE tau .25 and pairwise margin .1, weights 1/.5; best by validation SRCC.
- Default freeze: final two HTSAT blocks and BERT layers 10,11 plus projections/codebook; expose full-backbone variant.
- Source and dataset are untracked/outside repo; work in shared workspace to preserve source access.

## Review Focus

- CSV header variants and duplicate filenames must yield one valid row per pair.
- WAV sample rate/channel/PCM format must become correctly scaled 32 kHz mono.
- Loss must use `[B]` inputs so pairwise terms remain `[B,B]`.
- Loading pretrained versus loading fine-tuned Expert2 must retain distinct state-dict nesting.
- Frozen modules must stay in eval mode during training.
